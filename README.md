This site stores the code for a simple web based tool to calculate the LCOE (levelized cost of energy) for several commercial building generator typess
The tool takes situational input from the user.
The tool automatically goes out to several sources to get current average installation and fuel costs.
The tool uses the algorithm for calculation of LCOE given by the US dept of energy.
The html code for the tool was written with help from AI (GROK).
